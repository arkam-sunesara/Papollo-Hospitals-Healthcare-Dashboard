# Papollo-Hospitals-Healthcare-Dashboard
I’m thrilled to present Power BI Dashboard, where I analyzed a randomly created healthcare dataset to derive valuable insights. Note: Papollo Hospitals is a fictional entity, and the data used, along with the logo, is entirely simulated for learning purposes.
📊 Key Features of My Dashboard:
1️⃣ Patient Flow Analysis
Insights into admit, discharge, and follow-up dates to optimize patient care pathways.
2️⃣ Diagnosis Trends
Top conditions treated: Viral Infections, Flu, Malaria, Typhoid, Pneumonia, and more, enabling targeted resource allocation.
3️⃣ Bed Occupancy Rates
Visualization of occupancy across Private, General, and ICU wards for effective capacity planning.
4️⃣ Billing Insights
Detailed breakdown of bill amounts and health insurance claims to improve financial decision-making.
5️⃣ Doctor Feedback Analysis
Feedback volumes per doctor to measure patient satisfaction and enhance service quality.
6️⃣ Diagnostic Tests
Trends in CT Scans, MRIs, X-Rays, and other tests for understanding diagnostic demands.
This project is a significant step in my data visualization journey, showcasing how Power BI can turn complex data into actionable insights. I’m eager to refine my skills further and explore more datasets.
